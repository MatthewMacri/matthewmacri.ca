Web Services course project with Mahima Roy Karmakar, Cristian Racila and Alexander Nguyen. Datasets on
attractions, hotels, reviews and public parking that were never meant to work together, linked in a
relational model of seven tables behind a REST API. The plan includes an AI layer that suggests
activities, lodging and parking near each other.
